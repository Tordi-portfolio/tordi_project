POROSITY FORMULAS

Petrophysical Analysis and Reservoir Characterization

1. Basic Porosity Formula
φ = Vp / Vb
This is the fundamental definition of porosity. It represents the ratio of pore volume to bulk volume.
  • φ = Porosity
  • Vp = Pore Volume
  • Vb = Bulk Volume
2. Percentage Porosity Formula
φ(%) = (Vp / Vb) × 100
Used to express porosity as a percentage value.
  • φ(%) = Percentage Porosity
  • Vp = Pore Volume
  • Vb = Bulk Volume
3. Density Porosity Formula
φ = (ρma - ρb) / (ρma - ρf)
This formula is widely used in petrophysics for calculating porosity from density logs.
  • ρma = Matrix Density
  • ρb = Bulk Density
  • ρf = Fluid Density
4. Sonic Porosity Formula
φ = (Δtlog - Δtma) / (Δtf - Δtma)
Used with sonic logs to estimate formation porosity.
  • Δtlog = Formation Transit Time
  • Δtma = Matrix Transit Time
  • Δtf = Fluid Transit Time
5. Effective Porosity Formula
φe = Vconnected pores / Vb
Effective porosity includes only interconnected pores that contribute to fluid flow.
  • φe = Effective Porosity
  • Vconnected pores = Connected Pore Volume
  • Vb = Bulk Volume
6. Total Porosity Formula
φt = Vtotal pores / Vb
Total porosity includes both connected and isolated pores.
  • φt = Total Porosity
  • Vtotal pores = Total Pore Volume
  • Vb = Bulk Volume
7. Secondary Porosity Formula
φs = φt - φp
Secondary porosity develops after rock formation due to fractures or dissolution.
  • φs = Secondary Porosity
  • φt = Total Porosity
  • φp = Primary Porosity
8. Average Porosity Formula
φavg = Σ(φi hi) / Σhi
Used to calculate average porosity across multiple layers.
  • φavg = Average Porosity
  • φi = Layer Porosity
  • hi = Layer Thickness
9. Dual Porosity Formula
φt = φm + φf
Used in fractured carbonate reservoirs where matrix and fracture porosity both contribute.
  • φt = Total Porosity
  • φm = Matrix Porosity
  • φf = Fracture Porosity
10. Porosity Compaction Formula
φ = φ₀e⁻ᶜᶻ
Shows how porosity decreases with increasing burial depth due to compaction.
  • φ₀ = Initial Porosity
  • c = Compaction Constant
  • z = Depth
