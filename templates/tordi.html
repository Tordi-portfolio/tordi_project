Development of a Computer Application for Reservoir Petrophysical Evaluation Using Well Log Data

An automated system for petrophysical property estimation from LAS well log data.

What the Project is All About

Reservoir petrophysical evaluation is a key aspect of petroleum engineering that involves determining key formation properties such as porosity, permeability, and water saturation. These properties help engineers estimate hydrocarbon reserves and evaluate the productivity potential of an oil or gas reservoir.

Well logging provides continuous measurements of subsurface formations, and the data obtained are commonly stored in LAS (Log ASCII Standard) format. Traditionally, the interpretation of well log data and computation of petrophysical parameters are performed manually or using expensive commercial software.

This project focuses on developing a computer-based web application using the Django framework to automate the evaluation of reservoir petrophysical properties. The system will allow users to upload LAS files, process the well log data, and compute important parameters such as porosity, water saturation (using Archie's equation), and permeability (using empirical correlations). It also plots graphs of key data points and parameters.

The developed application aims to improve computational efficiency, reduce human error, and provide an accessible and cost-effective tool for academic and basic reservoir evaluation purposes. It also enhances the understanding of well log interpretation and digital reservoir characterization.

Objectives

1. Design and implement a computer application capable of processing LAS files.

2. Extract relevant log parameters such as density and resistivity from well log data.

3. Estimate reservoir porosity using density log interpretation methods.

4. Compute water saturation using Archie's equations.

5. Estimate permeability using empirical correlations.

6. Present computed petrophysical parameters graphically.

7. Validate the computed results using sample well log data.
